# 艾瑟兰纪：百层天穹塔

一款让 AI 自主探索、战斗、结识人物并持续保存冒险经历的在线文字爬塔游戏。

天穹塔的每一层都是一片可以自由行动的微缩世界，拥有安全据点、野外区域、迷宫、人物与守关区域。击败守关者后，冒险者才能开启通往更高楼层的传送阵。

游戏没有强制主线。AI 可以成为重武战士、荒野游侠、炼金术士、工匠、驯兽师等不同身份，也可以只做一个四处旅行的自由人。选择会留下任务进度、人物关系、传闻、伤势和 Boss 对挑战者的记忆。

第四层包含暗流前哨、荧光苔岸、沉没水道、废弃锻造大厅与核心锻炉。

- 追踪失踪探险队留下的蓝灯刻痕
- 挑战守关者“复燃熔炉巨像”

## 开始冒险

连接 MCP 后：

1. 调用 `aetherland_help` 查看公开职业和行动。
2. 调用 `aetherland_new_game` 创建角色。
3. 保存返回的 `session_id`，以后继续游戏时仍使用它。
4. 调用 `aetherland_get_state` 查看当前位置、任务和可执行目标。
5. 调用 `aetherland_act` 自主行动。
6. 出现 `pending_event` 时，必须使用 `choose_event` 选择后才能继续。

可以把下面这段话直接交给支持 MCP 的 AI：

```text
请连接《艾瑟兰纪：百层天穹塔》的 MCP。
先查看帮助，再创建一名你真正想扮演的角色。
请保存 session_id，自己决定探索路线、装备、交易、任务、事件选择和守关挑战。
遇到 pending_event 时请亲自选择，不要查看或猜测隐藏规则。
每完成一段冒险，请用中文告诉我去了哪里、遇见了谁、获得了什么，以及下一步想做什么。
```

## 公开行动

| 类型 | 可用行动 |
|---|---|
| 探索与移动 | `explore`、`move`、`visit`、`teleport`、`rest` |
| 人物与任务 | `talk`、`deliver`、`negotiate`、`commission` |
| 商店与公会 | `buy`、`sell`、`guild_accept`、`guild_turn_in` |
| 装备与制造 | `use_item`、`equip`、`unequip`、`craft`、`forge` |
| 剧情与战斗 | `choose_event`、`challenge_boss` |

具体可用目标会出现在 `aetherland_get_state` 返回的 `choices` 中，无需猜测内部 ID。

## 当前玩法

- 十一个开局身份与不同初始能力
- 四层独立的据点、野外、迷宫和守关区域
- 探索、采集、战斗、装备、制作、交易、委托和层间传送
- 天气、时间、水下探索、威胁度和哥布林生态
- 特殊人物、普通人物编号与跨层移动；对白会随地点、昼夜、天气和旅程进度变化
- 真假混杂的传闻、谈判、图鉴、成就与持久存档
- Boss 战斗报告、失败线索、伤势与跨回合反应
- 剧情事件暂停等待明确选择，不会自动替 AI 作决定
- 每层安全据点都有地区商店，限定商品、任务用品、当地料理与纪念品会给 AI 回访旧楼层的理由
- 前四层分别采用中欧矮人矿区、湖区水乡、高山游牧前哨、地下河港锻造遗产的生活与饮食气质
- 《天穹塔食谱册》当前收录20道料理；每层分为主餐、街头小吃、饮品、旅行干粮、稀有料理五类
- 首次品尝会永久登记，集齐一层菜单可获得地区称号；料理和地方装备会真实影响战斗、天气、探索或水下活动

v0.6.0 为前四层加入完整的地区货架与饮食骨架。橡木矿工杂货铺、月影渔具与食铺、流浪商人帐篷和暗流炼金屋各自出售只在当地取得的物品。MCP 状态会显示商品用途、楼层限定标记、当前料理增益、食谱进度与地区称号。

本版也会自动修正旧存档里串入第二层的猎鹰线索；风铃碎片集齐5枚后，可以在破损瞭望塔组装成可收藏的「山脊复音风铃」。

如果帮助页已有新动作，但 `aetherland_act` 仍只显示旧动作，这是客户端缓存了旧 MCP 工具参数。请删除原连接，再用同一个 MCP 地址重新添加，并在添加完成后开启一个新对话；无需更换服务器地址或重新开档。服务器端已经通过真实 `tools/list` 与动作调用验证。

## 更新路线

- 第 5 层：第一次基础转职试炼
- 第 6 至第 9 层：魔力、法术、职业装备与新生态
- 第 10 层：进阶职业、双修取舍与大型守关区域
- 后续楼层持续增加新城镇、人物、图鉴和跨层故事

我们不会批量生成只有编号变化的空楼层。新楼层会在拥有独立地点、人物、生态和事件后开放。

## 反馈

欢迎提交 Issue 反馈：

- 无法继续行动或存档丢失
- 事件选择无法处理
- 地图连接或楼层解锁异常
- 任务入口可见但对应行动无法调用
- 职业、战斗和资源平衡问题
- 重复文案、错误线索或不符合世界设定的内容

请勿在 Issue 中粘贴自己的 `session_id`。
