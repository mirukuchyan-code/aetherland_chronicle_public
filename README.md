# 艾瑟兰纪：百层天穹塔

一款让 AI 自主探索、战斗、结识人物并持续保存冒险经历的在线文字爬塔游戏。

天穹塔由许多彼此不同的楼层构成。每一层都是一片可以自由行动的微缩世界，包含安全城镇、野外区域、迷宫与守关区域。击败守关者后，冒险者才能开启通往更高楼层的传送阵。

游戏没有强制主线。AI 可以选择成为重武战士、荒野游侠、炼金术士、工匠、驯兽师等不同身份，也可以只做一个四处旅行的自由人。

## 开始冒险

连接 MCP 后：

1. 调用 `aetherland_help` 查看公开职业和行动。
2. 调用 `aetherland_new_game` 创建角色。
3. 保存返回的 `session_id`，以后继续游戏时仍使用它。
4. 调用 `aetherland_get_state` 查看当前位置、相邻地图与附近人物。
5. 调用 `aetherland_act` 探索、移动、交谈、露营或挑战守关者。
6. 出现 `pending_event` 时，根据事件内容选择，再执行 `choose_event`。

可以把下面这段话直接交给支持 MCP 的 AI：

```text
请连接《艾瑟兰纪：百层天穹塔》的 MCP。
先查看帮助，再创建一名你真正想扮演的角色。
请自己决定探索路线、装备、事件选择和是否挑战守关者。
记住并保留 session_id，不要查看或猜测隐藏规则。
每完成一段冒险，请用中文向我汇报旅途中发生的事情。
```

## 当前玩法

- 十一个开局身份与不同初始能力
- 每层独立的城镇、野外、迷宫和守关区域
- 探索、采集、战斗、装备、制作、休息和层间传送
- 天气、时间、威胁度和哥布林生态
- 特殊人物、普通人物编号与跨层移动
- 事件选择、传闻、图鉴、成就与持久存档
- AI 遇到剧情时会暂停，由玩家亲自作出选择

## 更新路线

- 第 4 层：扩充装备、长期委托和事件分支
- 第 5 层：第一次基础转职试炼
- 第 6 至第 9 层：魔力、法术、职业装备与新生态
- 第 10 层：进阶职业、双修取舍与大型守关区域
- 后续楼层持续增加新城镇、人物、图鉴和跨层故事

我们不会批量生成只有编号变化的空楼层。新楼层会在拥有独立地点、人物、生态和事件后开放。

## 反馈

欢迎提交 Issue 反馈：

- 无法继续行动或存档丢失
- 事件选择无法处理
- 地图连接或楼层解锁异常
- 职业、战斗和资源平衡问题
- 重复文案、乱码或不符合世界设定的内容

请不要在 Issue 中粘贴自己的 `session_id`。
